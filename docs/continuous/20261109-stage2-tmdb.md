# 阶段二：TMDB 独立栏目重构（验收进行中）

基线：9e2a33a，阶段一生产/测试6e53648已验收，不重复改播放器。现有PR #84和分支不变。

## 实际生产模块与接线

- TmdbBrowsePolicy：六页面/栏目定义、发行证据、国内比例、动漫可靠ID与系列关联。
- TmdbBrowseRepository：独立栏目与页缓存、官方候选接口、详情证据、单飞证明请求、3个全局网络并发上限。
- TmdbBrowseState：每栏分页/加载/错误、缓存恢复、活动栏目刷新暂存和离开后发布。
- TmdbBrowseRails：复用原生Poster/TvButton，四栏LazyRow、独立滚动、D-pad跨行、增量和重试。
- MainActivity：复用原顶部导航/Hero/详情/最近播放。移除旧全量混合首页加载；tmdbBrowseIndex仅用于查找详情与播放索引，
  栏目直接读取独立state.rows，不能用该索引拼装栏目。Top250保持原独立 /movie/top_rated 和250项分页。
- 搜索仍是 /search/multi，不搜索首页列表；复用缓存的IP归属，不在遥控器移动时联网分类。

## 栏目真实接口

首页：最近播放（本地历史）→热门推荐→国内热门。五分类：热门本分类→国内热门→最新上线→高分本分类。

| 栏目 | 官方候选接口 | 额外证据与排序 |
| --- | --- | --- |
| 首页热门 | /trending/all/week，仅保留movie/tv | 原周趋势顺序；不足以/discover/movie、tv补足尾部，不提前搜索影视仓 |
| 分类热门 | /trending/movie/week、/trending/tv/week | 分类筛选；类型Discover补足；双类型按各自原始排名交错，不按片名排序 |
| 国内热门 | /discover/movie 或tv?with_origin_country=CN/HK/TW | 详情实际production_countries/origin_country；popularity排序，再8/2/2分配与共同制作去重 |
| 最新电影 | /discover/movie?with_release_type=4%7C6&release_date.lte=当天&sort_by=primary_release_date.desc | 详情/movie/ID?append_to_response=release_dates确认已数字/电视发行；按已确认家庭发行日期排序 |
| 最新TV | /discover/tv?first_air_date.lte=当天&air_date.lte=当天&include_null_first_air_dates=false | 首播、最后实际播出、集数、播出状态共同验证；按首播日期排序 |
| 高分 | /discover/{movie,tv}?sort_by=vote_average.desc&vote_count.gte={300,100} | 客户端再次验证电影300票/TV100票门槛，再按评分排序 |

动漫with_genres=16仅作候选获取，不作为动画电影归动漫的证明；综艺TV genre10764/10767，纪录片movie/TV genre99。
电影与剧集页进一步核对最终分类。所有接口带zh-CN、page及适当include_adult=false；个人凭据/源URL不进入这些请求。

## 发行与IP边界

电影必须存在已发生的type4数字/type6电视日期。type1–3院线证据、未来家庭发行、只有普通release_date均不能当作已上线。
DVD/type5不当作流媒体上线证明。TV必须首播已发生、实际播出日期已发生、集数>0、状态为Returning/Ended/Canceled/InProduction之一。
未知标记UNKNOWN并报告数量，不猜测、不推荐；合法空栏保留状态/重试/更多入口。TMDB全球发行证据不等于本地源可播放承诺。

人工校正规则为明确TMDB ID：129/980477保留电影，635302/900667/568012分别关联85937/37854等已核查连载IP。
TV动画为连载类型；未知动画电影默认仍是电影，不凭标题或genre16变为TV。
后台读取已核查剧场版的belongs_to_collection，建立可靠collection→TV系列关联，识别同collection的新电影。
关联冲突则不作推断，缓存歧义；原始tmdb-movie-ID与tmdbTvId不改变，不把剧场版按电视选集处理。
未知候选不等待全站关联识别，关系学习完成后重算已缓存元数据。映射及冲突策略集中可维护。

## 缓存、性能与焦点

只读取当前导航页的栏目，不启动所有分类网络请求。网络Semaphore=3，IO/JSON解析离开主线程；
详情按账号单向指纹、类型/ID单飞复用（固定64条Mutex条带，避免逐片积累锁对象），栏目页6h、证据24h；离线保留最后有效页面。
目录tmdb-browse-v2，schema/语言/账号摘要隔离，不保存Token、任意私有响应字段或播放凭据。
页缓存最多64、详情512、关系64；仅保存有限公共字段及各发行类型最早有效日期，避免原响应膨胀。
启动先读取各页第一页的有界本地缓存；新分类立即使用自己的缓存，后台刷新。
每栏独立页号/失败/重试；追加去重，不重建其他栏目。只有末端海报获得焦点才自动增量，
“加载更多”按钮只触发一次，不因按钮移到新末端而自动连拉全部页面。
焦点所在栏目的整页刷新延后到用户离开该栏，保持key/顺序与scroll；Hero从当前分类首推/当前选择切换。
Hero original，普通海报w500；不因每次焦点变化访问IP关系接口。
