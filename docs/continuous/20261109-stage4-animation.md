# 阶段四：中心显现与白色柔光呼吸（已实现，统一回归待执行）

系统启动窗口仅黑底；Android12原生icon使用透明launch_empty，不出现第二套完整HERRIN。字标路径/位置不变，Compose首帧完全不可见，中心向两侧以透明至白色羽化波前显现1800ms。外侧初始alpha=0，不再预画低透明度全字标。

完整显示才准备首页并开始全字同步2400ms呼吸，正常至少4200ms后且本地缓存/首页结构就绪才启动340ms淡出。首页未就绪持续帧时钟呼吸，没有转圈。保留用户明确确定/返回跳过及系统减少动态例外。正常预算4540ms是用户要求的完整呼吸带来的设计时长，不冒称比旧2秒启动更快；首CPU绘制/焦点时限继续保留。

柔光是四层白色渐弱轮廓光，clipOutPath只作用笔画外，笔画独立亮度1→0.7→1；没有缩放、左右移动或每帧bitmap分配。预分配Path/Paint/Shader，withFrameNanos取实际VSync，不假设144Hz。首页与异步图片在完整显现后、呼吸期间准备，淡出揭示已绘制的底层，避免先淡到空白后解码背景。

必要验证：结构/许可证/唯一播放内核检查、Shell语法、TV门禁脚本4项通过。新增/加强：0/450/900/1800/2400/3000/4200ms实际Compose截图、初始零可见像素、中心先于两端、六字同步亮度、真实笔画外光晕、完整呼吸后再就绪、首页迟到持续呼吸、淡出底层非黑像素。保留显现前不挂载首页/跳过/减少动态/固定字标位置断言。

动画测试显式更新旧“显现结束即就绪”和2.5秒总预算合同，因为与用户新增完整2400ms呼吸不兼容；不删除测试、不放宽首帧/遥控器/页面切换门槛。预检从17增为19（新增两项）。FrameMetrics分开记录显现/呼吸/交接；真实冷启动API31复用已有startup工作流，随Debug成功后的APK执行，不使用录屏作为性能来源。
