# HERRIN M4.4 — TVBox 图片单仓全量影视站点预览

## 对应用户反馈

- 用户在其他 TVBox 中使用 `http://www.饭太硬.net/tv`，属于单仓配置。M4.3 已解析 JPEG 后的 `标记**Base64(JSON)` 附加数据。
- 外网样本恢复 49 个 `sites`、6 个 `lives`，但旧 TV UI 仅展示前 15 个站点名称；未直接进入标准 CMS 的 `csp_*` 站点也没有逐个可见状态。

## M4.4 实现范围

1. 保留当前快速预览、直播组导入和标准 CMS JSON HTTP(S) 试读。
2. 显示整个单仓的影视站点数、标准 HTTP(S) API 数、Spider/JS 适配器站点数。
3. 新增由遥控器操作的「查看全部 N 个影视站点」开关；展开后 LazyColumn 全量展示每个站点并可查询是否需要独立执行引擎，保留来源顺序，支持 49 个站点以及超过 15 个的单仓。
4. 多仓切到另一单仓时收起旧列表，避免旧数据与当前单仓混淆。
5. JVM 单元测试构造与外网观察形状一致的 49 影视站点、6 直播组 JPEG 尾随配置；Android TV 模拟器测试加载 49 个站点后展开、定位第 49 项、确认选择 `csp_*` 不触发额外网络请求。

## 不构成播放通过证明

此阶段能解析并完整浏览影视站点元数据、试读少数直连标准 CMS API；**不能**执行第三方 Spider/JAR/JS、私有采集器、视频解析脚本。未经审核的可执行文件不会被自动安装，也不声明所有站点可点播。实际 TCL TV 的播放、120Hz 流畅性仍需用户设备验证。

后续影视功能应先完成插件沙箱、兼容协议、许可证和来源合法性评估，再开发 `csp_*` 引擎与独立集成测试；不要将元数据读取成功率当作播放成功率。
