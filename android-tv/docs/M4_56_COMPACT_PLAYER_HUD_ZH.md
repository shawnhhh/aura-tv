# HERRIN M4.56 — 更轻的全屏播放控制条

## 来自 TCL 电视实际照片的后续优化

用户反馈实机画面没有铺满、播放屏幕左上角永久显示「返回详情」「仅播放有权使用的媒体」「查看实播状态」等开发文案。M4.55 已对 Media3 PlayerView 默认启用 `RESIZE_MODE_ZOOM`、保留原比例选项并彻底删除普通播放器的左上角文字（不是挪到别的位置），完整 Android Debug + TV Emulator CI **均成功**：111 个设备测试通过，最新基线 HEAD `441063c8`。

M4.56 聚焦照片里剩余的另一个问题：原来的控制板过宽、过高，用户只是想暂停或快进，却要同时看到六个功能按钮、音轨、字幕、弹幕四项、选集及画面比例，遮住了大量视频。

## 实际修改

- **普通播放器默认精简**：进度、当前/总时间 + `−10s / 播放暂停 / +10s / 更多` 四个按钮；不立即创建倍速、音轨、字幕、弹幕、画面设置、选集等十余个焦点节点。没有删除任何播放功能。
- 按遥控器 OK 选中「更多」后，展开此前的倍速、音轨、字幕、选集/线路、弹幕、画面比例；按钮变为「收起」，可随时恢复精简版，播放不中断。
- 缩窄控制板：从电视宽度 86% 减为 **78%**；下边距 36dp → 24dp；内边距与行距减小。视频已在 M4.55 居中裁切铺满，精简控件后减少被遮挡面积。
- 播放中精简版自动隐藏时间从 8 秒缩短到 **4.5 秒**；用户明确展开的控制面板仍给 8 秒操作时间。暂停时保留控制板，便于恢复播放。设备用户任何遥控按键都会重新计时。
- 真实焦点移动：从播放暂停按钮按 DOWN 时，如果精简版则聚焦「更多」；展开且有选集时仍保持旧的直接到「线路」/「选集」的焦点路径。**从主播放按钮行按 UP** 可以隐藏面板回到视频，**从展开后设置子行按 UP** 则返回上一行，不再因为父级预览按键把整个控制条提前关闭。
- `−10s` 与 `+10s` 按钮现在和遥控器左右快进共用 `applyRemoteSeek`，及时更新屏幕上的进度与时间，不再只能等待下一个 500ms 播放器轮询。
- **永远不重现已删除的左上角文字**。老的开发者诊断仅在 `src/debug` 的隔离测试宿主中可用（`testDiagnostics=true`），用户的正常播放不出现播放源、技术信息和原「返回详情」按钮。

## 边界

- 中心裁切保留视频人物比例，但裁去部分边缘；如果源片自己编码了黑边，单纯的 AspectRatioFrameLayout RESIZE_MODE_ZOOM 不会智能抠除内嵌黑边，不能假称真机所有片源均消除黑边。
- Android TV SwiftShader 模拟器不能代表 TCL T7L Ultra 的硬件 HDR/杜比视界/刷新率或实际光子响应。此项 UI 调整尚未在用户电视上安装测试。
