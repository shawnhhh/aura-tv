# M4.2 — 家庭 IPTV 单次导入与免常驻代理播放（Draft）

## 目标与明确限制

- 用户家庭：重庆联通 IPTV 机顶盒（临时接入）、小米 BE3600 Pro 网线版、TCL T7L Ultra 电视。
- 初次获取频道时允许借助机顶盒及临时 Mac 抓取、筛选和检测，不将机顶盒、Mac 或 NAS 作为日后播放依赖。
- 后续只有路由器和电视保持运行。HERRIN 本地保留一次性导入的频道 M3U，不需要保持原始 M3U 文件或抓取电脑在线。
- **必须有电视可直接连通的媒体服务器**，且流地址不依赖离线后失效的机顶盒、短时鉴权或中间代理。单播播放不能替代联通的专用 VLAN、鉴权和运营商访问条件。
- 当前仅解析由用户手动提供的 HTTP、HTTPS、RTSP 单播链接；**不支持** `udp://` / `rtp://` 组播、组播 RTP、DRM、机顶盒协议逆向或运营商鉴权绕过。不预装或分发任何直播源。

## 一次性工作流

1. 保留当前 IPTV 原始接线与设置，先测试机顶盒播放正常，记录当前网络接线。不要修改光猫、路由器的 IPTV VLAN、WAN 模式或机顶盒绑定。
2. 临时将机顶盒接到可采集的位置，通过用户自己的旁路镜像抓取播放时的流量，制作 `family.m3u`（UTF-8）。直接抓包不会破坏原机顶盒服务；抓包需要交换机镜像口等条件，在普通 Mac Wi-Fi 上不能直接捕捉另一台有线机顶盒的数据流。
3. 筛选 `http(s)://` 或 `rtsp://`，排除依赖临时代理端口、机顶盒自身 IP、UDP/RTP 组播、含密码的 URI。请注意：仅凭 URL 格式不能证明线路能直接播放。
4. 复制 `family.m3u` 到电视可访问的 U 盘/本地文件位置；启动 HERRIN → 设置 → 家庭 IPTV → 选择本地 M3U 文件，完成一次性导入。
5. 打开 HERRIN 的「直播」选项卡；单独尝试至少三个频道，并通过「查看实播状态」确认确有视频帧、声音和稳定解码。
6. **关键验收**：拔掉联通机顶盒，关闭 Mac/NAS/抓包设备，等待数分钟后再次切台、重启 HERRIN，再次验证直播；最后确认只有小米路由器、TCL 电视和运营商网络仍保持工作。

**如果第 6 步失败**：直播 URL 可能依赖机顶盒会话/鉴权、IPTV VLAN、组播或临时转换服务。不能通过一次性提取自动解决；需寻找在电视当前网络中原生可访问且受授权的单播服务。不会自动打开路由器端口、注册后台服务或部署代理。

## M3U 格式例子（虚构地址，不是可用频道）

```m3u
#EXTM3U
#EXTINF:-1 tvg-id="local-news" group-title="本地",测试新闻
rtsp://192.0.2.10:554/live/news
#EXTINF:-1 group-title="其他",测试频道
https://example.invalid/live/test.m3u8
```

导入解析器最多接受 512,000 字节、250 个不同频道；跳过无效/重复链接和不支持的 scheme，拒绝空频道列表、错误的 UTF-8 和误导入的 `#EXT-X-` 视频分片清单。用户私人播放链接原文只在应用的私有本地存储中保存；收藏采用按来源隔离的散列值。任何人分享 M3U 前应删除访问 token/账号信息。删除 HERRIN 应用数据会清除频道列表（因此保留自己导出的 M3U 备份）。

## 播放与兼容性

- Media3 RTSP 模块处理受支持编解码格式的 RTSP 单播 RTP（UDP 或 interleaved TCP），不支持 RTP multicast。
- `http(s)` 直链依赖实际媒体容器/编码； `.m3u8` 按 HLS 播放。电视播放器的 HEVC/音轨支持依赖设备解码能力。
- 只有源站位于可访问的内网/运营商网络且无需长期机顶盒续签时，拔掉机顶盒后才可能继续使用；地址指向已关闭的 Mac 或机顶盒的情况一定会失效。
- TCL 的文件提供器能力受系统版本和预装应用影响，必须在实机上验证 USB 文件可被 `ACTION_OPEN_DOCUMENT` 选中；本次不声称已经在真实电视或真实联通线路上验证。
- 家庭来源与原有 HTTPS 订阅相互隔离；选择家庭来源不会放宽其它目录、测试流与远端 M3U 的 HTTPS 校验。

## 自动化 / 实机验收计划

- JVM：解析 HTTP(S)/RTSP、中文分组、过滤组播、重复频道、超限、HLS 清单、URI 凭据、HTTPS 原有严格规则的回归测试。
- 静态校验：`python3 scripts/check_static.py`；编译 `./gradlew :app:testDebugUnitTest :app:assembleDebug`。
- 人工模拟器：系统文件选择器、返回/取消、安全覆盖、重启后来源保持、RTSP 单播模拟服务器解码。
- TCL 实机：文件选择器可用性、频道焦点/收藏/切换、机顶盒断电状态下的直播、网络中断与恢复、路由器无需修改网络模式。以上均待用户实机操作验收。

未包含：自动抓包、修改光猫/路由器 IPTV 配置、直播源扫描、组播转发/代理、账号提取、DRM 绕过或保证真实频道列表长期有效。
