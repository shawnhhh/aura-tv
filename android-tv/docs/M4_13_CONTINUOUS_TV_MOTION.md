# HERRIN M4.13 — 首帧衔接与遥控器导航动效

## 用户反馈和本轮边界

- 首页进入与 HERRIN 启动画面之间不应该闪一次深色空屏。
- 顶部分类按钮靠遥控器横向切换时，当前控件的焦点必须立刻可操作；动效只能跟随它，不能延迟、抢焦点或造成布局跳动。
- 上一轮已经统一海报卡外框尺寸、对远程海报使用完整适配。本轮不再用整体缩放卡片来冒充视觉动效，避免「最近影片」邻卡被裁切。

## 实现

1. 启动动画完成后暂留一层不透明的 H 字标，先让首页内容与背景在其下开始绘制；随后在约 460ms 内淡出字标，同时首页内容淡入，避免「移除黑色启动层 → 首帧仍不可见」的明显断层。动画跳过、系统关闭动画设置及减少动态效果仍有效。
2. 顶部六个导航按钮各自保留原生 `FocusRequester` 与即时白色聚焦态；新增一个不可聚焦、不可点击的细下划线轨道，按照布局实际测得的各按钮中心，以可打断的弹簧动画滑动。离开顶栏后轨道返回所选栏目；减少动态效果下直接定位。
3. 自动化 UI 交互测试等待启动幕真正退出之后才发送方向键；增加启动幕与首页重叠时序测试、下划线不可抢焦点和左右导航测试。

## 验证与限制

- CI Android Debug：编译、单元测试、lint 与 APK。
- API 30 电视模拟器：应用启动、方向键、海报不跳尺寸及所有既有测试。
- TCL T7L Ultra 的遥控器手感、OLED/LED 实际黑场观感、启动首帧时长与高刷新率帧间隔，仍须实机确认。
