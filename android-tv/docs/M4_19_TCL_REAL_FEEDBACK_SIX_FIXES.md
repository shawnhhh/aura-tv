# M4.19 — TCL 实机反馈六项修复

本轮依据用户 TCL T7L Ultra 的七张实机照片（未将照片提交仓库）。

## 已实现

1. **直播频道**：同名/高清后缀节目合并为一个可选项，保留所有不同且原列表授权的播放 URL；点节目可选「线路 1/2/...」。首页直播列表与全屏频道抽屉同步采用线路选择，收藏过滤按节目多线路聚合。没有猜测或增加任何未知直播 URL。
2. **首页焦点与滚动**：浏览列真正支持纵向滚动；第一排海报 D-pad 下键先滚至下一排再聚焦，向上滚回。标题与详情保留全宽，修正 80 部影片后「热门推荐」出屏问题。
3. **选集即播**：点击每一集时选用该集第一条已有线路，并直接进入播放/Spider 解析；点击某个线路也直接播放，不必再按「解析并播放」。选集与线路可横向滚动。
4. **播放容错/定位**：Spider 返回多个合法候选直链时，把候选通过子进程 IPC 传给 Media3。遇 Media3 I/O 错误时按原源返回顺序自动尝试备用地址；显示安全的 Media3 错误代码与 HTTP 状态码，不泄漏播放 URL、请求头或 token。用户本次允许 HTTP 时才允许媒体跨协议重定向；仍拒绝未知网页解析、主动嗅探。即使 `parse=1`，已经是显式 `.mp4/.m3u8/.mpd` 的直链可直接播放。
5. **倍速**：播放器新增遥控器可聚焦「倍速」按钮，按 0.5/0.75/1/1.25/1.5/2 倍循环，使用 Media3 原生变速。
6. **壁纸品质**：优先使用片源本身提供的 `vod_pic_slide` 等单独背景 URL，首页最高解码约 2560×1440、ARGB_8888；低分辨率竖海报不再直接拉满电视，以柔和背景+右侧等比例海报替代。清理详情 `&nbsp;` 等 HTML 实体。**不是搜索全网或 TMDB 自动刮削**：独立高清素材没有来源或许可时不伪造配图。TMDB 图片检索需要用户持有的 API 凭据，当前未调用。

## 验收边界

- 静态检查与新单测覆盖分组、字幕/线路 IPC、倍速和文本清理；新增 Android TV UI/媒体测试检查首页下键、倍速与实解码后备线路切换。
- 本地 Gradle 缓存不完整；以 GitHub Actions Debug 编译、单测、Lint 和 Android TV API30 模拟器 CI 结果为准。
- **真实饭太硬插件已在用户实机返回 80 部影片与授权选集；当前照片播放器仅提示网络/服务器不可用，未有实播成功证据。** 新容错与错误编码待同一 TCL/同一线路复验；不把模拟器自制 HTTPS 测试视频视为第三方流可播放。
- 不合并 Draft PR #30；不将第三方插件、片源或私有 URL 打包进 APK。
