# HERRIN M4.57 — 四项 TCL 电视实拍反馈修复与验收

## 真实问题与本轮处理

**1. 已保存 TMDB Read Access Token，20/20 已处理但匹配 0 部。**
原始版本把“已尝试匹配的数量”当成能连通 TMDB 的证据，但授权不成功、DNS 超时、TMDB 服务失败、影视源片名不完全匹配，最终全都只显示 0，原因不可见。
- 新增 `TmdbConnectivityProbe`，只请求官方 `https://api.themoviedb.org/3/configuration`，区分未配置、令牌格式无效、401/403 未授权、网络/DNS 不通、服务错误及确实已连通。只存储/发送用户自己的 v4 读访问令牌，界面/日志均不回显。
- 设置页展示实际 TMDB 连接状态。已连通、扫描完成而匹配为 0 时，明确提示“片名、电影/剧集分类或本站未提供对应元数据”，并引导详情页“纠正影片资料”。无法连通则不要声称刮削成功。
- 匹配保持保守：宁可保留原海报，也不把另一个同名/不同年份的作品乱套上去。实际 20 部是否全部可刮仍取决于 TV 上能否访问 TMDB 及片名是否存在，**不能脱离真实网络和私人 Token 伪造成功率**。

**2. 播放报 ERROR_CODE_IO_NETWORK_CONNECTION_FAILED。**
此码属于当前视频流网络连接失败或超时，并不能直接定性为“解码/解析器出错”。现有 Media3 网络错误分类保留，失败浮层新增“切换线路”“返回选集”按钮，在当前影片来源上换一个合法直链或集数；单纯重试仍可用。已经返回的 HTTP/DNS/播放错误不尝试凭电影名推测、生成新的影视 URL，也不会擅自连接其他影视站点。若第三方站点失效、域名受限或需要 TVBox 独有的 JS/Spider 授权解析，应用本身无法保证该源一定能播放。
  
**3. 点击海报不能直接播放；必须先到影片详情，点具体集数播放。**
- 首页/分类/搜索/推荐中的 `openMovie` 全部统一转到 `details(item)`，取消 M4.54 的“一按即播”逻辑。首页主焦点按钮同步变为“选择集数与线路”，不再绕过详情直接启动。
- 已在详情页的 CMS 影片，仅对**用户选择的一个 vod_id**读取缺失的详情/选集；读完显示真实选集（不虚构 URL），由用户明确按下具体“第 N 集”或线路后才进入 Media3 播放器。
- 对第三方影片详情的首个“▶播放授权片源”自动播放入口改为“请选择下方具体集数或播放线路”。来源提供真实授权地址才会播放；空详情页面显示“重新读取选集”可重试，不扫描全部影片。
- 60 片库、错误 vod_id 和列表预带多线路的模拟器用例，改为要求 **海报→详情→选集→播放** 的真实键盘/焦点链路。

**4. 启动 HERRIN 没有滑动消失。**
- `SplashExitCurtain` 原来只有 `alpha 1→0` 淡出，没有任何位置移动；已修改为物理横向滑出右侧（translationX 从 0 到窗口宽度），首页在底下提前绘制。
- 遵守系统减弱动态效果：reduced motion 则立即退出，不强制动画。原“完整 HERRIN 标识到主页”的单屏语义不变。
- 增加真实 Compose 动画时间轴断言：动画中 `splash-curtain` 的左边界必须真正横向移动，不能只有 alpha 消失。

- `M438SingleWarehousePerformanceTest` 仍然加载 12 站点 60 影片；选中第 16 张，点击不播放，先到详情，只解析所选 vod_id，再点第 1 集才进入播放。原 D-pad 焦点、P95/帧采样不减少。
- `M454CmsOneTapRecoveryInstrumentedTest` 既有两项用例更新为详情优先：错误 ID 拒播、详情重试、具体选集才开始播放；列表已有两线路则无需重复请求 CMS 详情。
- `HerrinSplashTest` 增加启动遮罩真实空间位置变化断言。
- 其他 M4.56 之前的 110+ 项遥控器、字幕、播放器、缓存与画面比例测试全部执行。只要当前 HEAD 的 Android Debug/JVM/Lint 或 Android TV Emulator 任何一条失败，不能宣布已验收。
