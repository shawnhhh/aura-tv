# HERRIN M4.12 — 设置输入表单与直播抽屉的遥控器路线

## 范围与目标

延续 M4.11 的跨排纵向焦点修复：电视遥控器的一次方向键应该到达视觉合理的下一控件，不能丢焦点，也不能因为目标不在 LazyColumn 视口而吞掉按键。

## 本阶段实现

- 紧凑设置页（保留既定的**两个**输入框：影视源和直播源）明确纵向路线：返回 → 影视源输入 → 应用影视源／选择影视点 → 直播源输入 → 应用直播源 → 返回首页 → 高级工具。上键反向返回；从「选择影视点」向下再向上会回到原横向按钮。
- 在小屏幕或滚动较远的情况下，目标若不在 LazyColumn 的已挂载项目中，先有限时平滑滚动，再请求焦点；已挂载时立即移动。不会读取 LazyList 的 layoutInfo 来触发每帧重组。
- 直播全屏抽屉开启时，先滚到当前播放频道，聚焦它而非总跳到第一个频道。分组向右进入频道、频道向左返回当前分组、首行频道向上回查找、查找输入框向下进入频道（空列表时回分组）。收藏星标向左回到同一行频道。
- 收起抽屉或选中频道后，显式恢复全屏播放器的 D-pad 焦点锚点，使下一次左键／确定键可以再次打开频道列表。
- 为紧凑设置路线增加纯 Kotlin 单元测试、真实 Activity 遥控器按键测试；扩展直播抽屉回归测试（左右、上下、关闭后再打开）。

## 回归与尚未覆盖

此文档仅记述代码变更，CI 及模拟器运行结果以 PR 最新检查为准。高级诊断中更深层的可变来源列表、直播 30+ 频道快速滚动和 TCL T7L Ultra 真机的长按手感仍需下一轮专项验收。饭太硬 Spider 保护插件的真实影片、封面、选集及播放也尚未获得实机证据。
