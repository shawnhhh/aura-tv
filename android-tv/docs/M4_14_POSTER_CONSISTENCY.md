# HERRIN M4.14 — 最近影片 / 热门推荐海报比例专项

## 用户观察

- TVBox、Spider 影视源的 `vod_pic` 通常是竖版，而 HERRIN 的横向影片轨道使用横幅卡片。
- 只用 `ContentScale.Fit` 虽能避免裁切，却在竖幅两侧留下大片单色空白，真实封面显得尺寸忽大忽小。
- 拉取第三方海报之前显示离线演示电影的图片，会造成与影片标题完全不对应的瞬时画面。

## 实现原则

1. 首页「继续观看/最近影片」与「热门推荐」仍统一采用 **217×116dp** 卡片外框，图片区域独立、标题栏固定 29dp，焦点只上移 2.5dp 而不放大整个卡片。不会因为横幅或竖幅图片切换改变 LazyRow 的节点宽高。
2. 新 `PosterArtwork` 专供卡片：实际封面以 `ContentScale.Fit` 完整居中呈现，不能裁断顶端和底端；同一封面以低亮度的填充式背景铺满外框，缓解竖幅两边大片死黑区域的观感。背板不是另一张影片的图。
3. 对配置了真实 `artworkUrl` 的外部影视源，拉取前使用统一的 HERRIN 深色占位，不先闪一张不相关的原创演示海报；失败后占位持续保留。
4. 缓存读取、URL 校验和下载大小限制复用现有 `AuthorizedPosterCache`，仍不包含第三方影视封面资源；远程加载成功后淡入，减少动态效果时直接显示。
5. 新模拟器测试通过 MockWebServer 提供合成红/蓝 PNG 竖幅和横幅，检查两张卡片框尺寸一致，且前景图片的顶部/底部都可见；另测 404 占位。

## 验收界限

Android Debug 编译/单测/Lint 与 API 30 Android TV 模拟器结果以本版 GitHub Actions 最新提交为准。TCL T7L Ultra 不同系统版本的 GPU 背景效果与饭太硬真实 `vod_pic` 图片仍需实机验收。
