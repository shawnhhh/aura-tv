# HERRIN M4.23 — 评分筛选、影视详情资料、技术规格可信标识

## 产品行为

- M4.22 影视库筛选增加「影片评分 · TMDB」，分组 ≥9/8/7/6、低于 6、未评分。评分与演员、导演、国家/地区、首映年份、分类执行 AND 交集；只有真实 TMDB 数值进入评分档，来源不明的数字不冒充 TMDB。
- 详情页展示官方 TMDB 评分（明确标注来源）、上映日期、分类与细分类、地区、导演/主创、剧情简介、可用时的片长；剧集使用「单集约 X 分钟」，避免把 TMDB 单集时长当整剧时长。旧的播放进度存在才显示继续播放，从不造出时间。
- TMDB 官方 detail+credits 提供导演、演职人员、角色和可用时的头像 `profile_path`；头像只从 `https://image.tmdb.org/t/p/w185/...` 加载。无头像降级姓名首字，最多 10 位演职人员；信息行是 TV 可聚焦的横向 LazyRow，按左右键可以滚动更多人物。
- 高清海报、背景、简介与人物肖像仅为**展示资料**。影视源的影片 ID、线路、集数、URL 不被改写。旧 M4.22 正缓存没有头像/日期/片长，新 `detail-v3` 键使安装升级后自动补齐，不要求手动清缓存。
- 视频规格分为两个不能混淆的来源：
  1. `播放器已识别轨道`：用户实际打开媒体后，Media3 **已选中**视频/音频轨道的 Format。显示有依据的 4K/1080p/720p、Dolby Vision（明确 video/dolby-vision MIME）、HDR (PQ)/HDR (HLG)（实际 color transfer）、Dolby Atmos（明确 audio/eac3-joc MIME）。PQ 不可单独确认 HDR10；不推断 HDR10+。
  2. `影视源标称（未经播放验证）`：仅从影片/线路**文字**中严格匹配 2160p/4K、1080p、720p、HDR、杜比视界、Atmos。两个层级使用不同文字和颜色；无信息则显示「播放后识别」。不从 URL/域名/片源海报猜规格。
- 已识别结果在本次会话按目录作用域、刷新代次、影片、集数、线路和源 URI 关联，换集换线不能将旧 4K/DV 误挂在其他视频上。已识别格式**不等于**电视面板实际触发 HDR/DV/Atmos 输出，也不代表硬解或正常播放。
- 不显示无法可靠得到的网络媒体文件大小（尤其 HLS 的 Content-Length 不代表完整片长），也不虚构 Blu-ray 体积。
