## 已实现

### A：遥控器与主线程

- 首页剧集分组和折叠投影改为 Default dispatcher；取消过期投影后才允许发布，焦点不等待网络/图片。
- 保留原有立即焦点反馈及 latest-wins 聚焦任务；记录长按 repeat KeyEvent。
- 凭据安全写入离开输入主线程；安全存储失败显示恢复提示。
- 扩展真实系统输入回归：120 次连续反向导航、110 个长按重复事件与松键后焦点稳定；P50/P95/P99 焦点回调指标。
- 新增有界窗口 FrameMetrics 采集：渲染帧耗时分位数、按实际刷新周期计算超预算样本、指标回调丢失、GC 累计时间增量。回调频率包含空闲间隔，不冒充持续 FPS。
- 偶发闪退沿用已有 MainExitDiagnostics；尚无本轮用户 TCL 异常堆栈，不能声明定位或修复未知真机闪退。

### B：高刷新率

- 去除 `<=120.5f` 上限，支持系统实际开放的 90/120/144/165/240Hz 等模式。
- 只选择当前物理分辨率下不低于当前刷新率的可用模式；同时设置 modeId 和刷新率提示，避免降到 1080p。
- 生命周期创建时请求一次，重复值不重设；不加入播放期间切换逻辑，不改视频帧率/HDR/杜比视界/解码核心。
- 设置诊断显示系统模式、当前输出、窗口实际请求和窗口帧测量。策略正确不等于系统实际采用，也不等于 144fps。

### C：TMDB

- 所有业务 API 地址统一由 TmdbEndpoints 管理：`api.tmdb.org/3` 优先，`api.themoviedb.org/3` 回退。
- DNS/TCP/TLS/超时及 500/502/503/504 只进行一次安全 GET 故障切换；共享 60 秒冷却，避免每条首页请求重复试坏主域名，随后允许探测切回。
- 401/403/429 不触发端点轮换；保留真实 HTTP 状态诊断和现有元数据缓存。
- 剧集分集请求网络失败可回退旧缓存；original 大背景与来源图片策略保留。
- 图片 CDN 新增不携带凭据的独立 HEAD 诊断，明确 HTTP 可达不代表 API 或具体图片可用。
- 个人 TMDB Token 迁移至 Android Keystore AES-GCM 支持的存储，不再新增明文 Token；读取缓存避免反复解密。

### D：局域网配置中心

- 设置 → 高级工具与诊断 → 手机扫码配置；本地 ZXing 二维码，不使用在线二维码服务。
- 临时 HTTPS，绑定本地 IPv4 和随机端口；256bit 配对能力、电视确认、一次性换取独立管理能力；配对 3 分钟，管理闲置 30 分钟；编辑活动可保活，主动结束及离开对话框关闭服务。
- 二维码仅含一次性配对能力，不含业务 Token/密码；能力放 URL fragment，手机加载后清除 fragment，配置通过请求正文传输。
- 同一个会话切换 TMDB、影视源、直播源、NAS；Token 修改/删除/测试，主 TVBox 单仓/多仓配置即时应用。
- 附加服务使用现有 `herrin` Preferences，业务适配器直接读取；不建独立手机数据库。支持最多每类 10 条附加配置：新增/编辑/删除/启用/停用；影视地址批量验证、去重、原子保存。
- 附加影视源加入既有数据仓库搜索路径，不授权自动执行新 Spider；附加直播由现有 M3U/EPG 仓库加载合并；NAS 使用既有 WebDAV 适配器、独立 Keystore 凭据与连接测试。
- API 限制 Origin/Host、正文长度、JSON 类型；不回传密码或 Token；删除附加 NAS 时移除密钥。

**可信传输限制：** 本版为会话临时自签名 HTTPS，手机必须人工核对电视完整 SHA-256 指纹后才能建立信任。手机页面要求确认；不能核对的 Safari/Chrome 环境应使用遥控器配置。没有实现系统默认信任或自动证书部署，不能宣称免证书操作的一扫即用已全面验收。没有明文 HTTP 敏感配置提交路径。

**能力范围：** 扫码新增配置目前限定 HTTPS。NAS 本轮仅声明 WebDAV，不声明 SMB/NFS；网络、端口、路径由完整 WebDAV URL 表达。附加影视源主要接入 TMDB 播放前搜索路径，主首页 TVBox 导入仍使用现有主配置。旧版授权目录 CatalogProfiles 的手机编辑仍待接入。

### E：启动动画

- 使用现有白色完整 HERRIN 矢量字标，纯黑背景，位置/尺寸/间距固定。
- VSync 帧时钟驱动 1800ms 中心向外柔和透明度遮罩；完整显现前无呼吸、光晕、缩放或移动。
- 显现后所有字母统一呼吸，只影响字形 alpha；首页本地/缓存投影完成后平滑淡出。
- 首页从首帧在幕布下组合，不等待 TMDB；保留离线内容及 reduced motion。无 H-only 或圆环。
