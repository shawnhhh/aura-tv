# HERRIN M4.11 — 遥控器纵向焦点路线

用户确认的预期：方向键必须移动到视觉上合理的可操作控件；焦点即时响应，跨影片排保持相近横向位置，必要时平滑滚动，不出现无响应或跳错位置。

## 本轮实现

- 首页上、下两排影片建立双向路线。向下从第一排第 N 张进入推荐排对应位置，向上原路返回；目标不在 LazyRow 当前视口时先滚动使其挂载再请求焦点。
- 两排间滚动尽量维持原卡片的屏幕横坐标；减少动态效果选项下直接定位。快速重复按键期间不发起叠加的跨排滚动任务。
- 第一排向上按照位置回到「播放」或「影片详情」，而不是所有卡片都强制跳回最左侧「播放」。
- 搜索页建立输入框 → 分类/排序 → 快捷关键词 → 搜索结果的纵向路线，结果按下键止于末行，向上可返回对应快捷关键词。
- 顶部导航下键对准当前页面真正附着的目标；修复直播无频道时「设置授权直播列表」缺少焦点请求器的问题。
- 从首屏动作向下时优先聚焦当前可见的第一张海报，避免试图请求早已滚出视口的第 0 张卡片。

## 自动化验收

`HerrinUiSmokeTest` 增加同列跨排往返、第二列对应映射以及搜索筛选/快捷词/结果焦点路线测试。该测试基于真实 Activity 和 `sendKeyDownUpSync` 遥控器事件，模拟器跑完全套回归后再发布结果。

## 边界

本轮优先修复用户指出的首页影片排及搜索页焦点路径；设置页的深层表单、直播播放器抽屉、实际 TCL 遥控器长按惯性和屏幕 overscan 仍须单独验收。模拟器不代表 TCL 真机体验。
