# HERRIN M4.10 — 启动、过渡、焦点与影片卡片

## TCL T7L Ultra 用户反馈（2026-10-28）

- 点击应用后，出现 HERRIN 过场动画之前有明显的等待感。
- 启动字标收拢与进入首页的衔接过于机械，导航切换时内容突然跳变。
- 遥控器向下键偶尔无法进入预期按钮。
- 「最近影片」的海报被裁切；聚焦切换时卡片尺寸不一致。

## 本轮改动

1. **原生启动窗口**：增加深色底+白色 H 的预绘制背景；Android 12+
   使用系统 SplashScreen 背景和 H 图标。在 Compose 首帧之前便有品牌标识。
   这解决的是视觉等待感，真实冷启动耗时仍需实机测量。
2. **启动动画**：字母先柔和显现，再以非线性时间曲线、逐字透明度
   向中心 H 收拢；进入首页时内容淡入和轻微上移。保留遥控器确定键跳过
   与减少动态效果设置，不在每次切换栏目时重播启动动画。
3. **页面与焦点**：导航按钮的填充/文字颜色渐变，首页影视背景淡入切换，
   栏目内容做短时柔和过渡。导航栏和搜索/设置入口的遥控器下键显式指向
   对应内容；首页主操作键下键进入第一张影片卡片。
4. **影片卡片**：尺寸固定，不再把焦点卡整体放大 7.5%。改用细边框及
   2.5dp 轻微上浮；`vod_pic` 使用完整适配（Fit）而不是填满裁切（Crop）。
   标题移到独立底栏，避免遮挡海报下缘；远程海报载入后淡入显示。

## 自动化验证

- `python3 scripts/check_static.py` 和 Android Debug 编译/单测/Lint/APK。
- Android TV API 30 模拟器：现有全套遥控器/UI/播放测试，以及新增
  导航下键到主操作、到首张影片卡片的路径验证。
- 新测试检查同一张海报获得/失去焦点前后的几何尺寸不变，并保存截图。
- `scripts/emulator_smoke.sh` 记录启动用时 (`launch.txt`)、1 秒截图和
  首页 5 秒截图，供启动过场审核。

## 仍需 TCL 实机验收

真实冷启动速度、60Hz/120Hz 下的动画帧率、遥控器长按重按、电视 overscan
与海报观感都需要在 TCL T7L Ultra 检验。模拟器通过不等于实机通过。
