# HERRIN M4.50 — 内容来源页面去除开发者术语，保留高级诊断

## 发现的不适合普通用户的交互

审查 M4.49 及此前电视 UI 源码时，发现「影视源 · 应用」「选择影视点」两个消费级页面仍直接展示 `Java Spider`、`Spider 子进程异常退出`、`JAR` 等内部运行时状态。用户此前明确期望点选影视内容后直接进入播放，不进入解析详情或看到开发调试过程；即使普通配置页还在显示这些实现词，也会造成不必要的学习成本。

## 已修复

- 新增 `ConsumerSourceStatus.display()`：普通影视源导入状态（`compact-tvbox-status`）及「选择影视点」列表状态（`source-site-status`）使用面向用户的表达。
- 普通状态保留明确的**站点数、直播配置数、已导入/未导入**等业务信息；检测到技术细节时只显示“正在连接影视点”“当前影视点暂时无法打开，已停止自动重试”“请选择其他影视点”等可操作提示，不展示底层运行时类型、子进程、原始故障路径。
- 影视点列表的两段说明调整成“选择影视点后才加载对应目录，部分来源需要额外组件”及“部分站点需登录授权；现有应用不保证所有授权弹窗可用；优先选择无需登录的合法直连站点”。不会暗示用户已登录，也不绕过登录/DRM。
- **高级设置及内部排障数据保持原样**：开发者仍可以查看详细底层状态，保留 CI 与后续诊断证据。
- 5 项 JVM 单测涵盖数量信息保留、异常原因不外泄、加载状态、普通状态、未知技术异常。新增 Android TV 原生遥控器 UI 测试，进入「影视点」页面后检查提示包含授权限制，但不包含 Spider/JAR/子进程等术语。

## 验收

- 本 HEAD 必须通过 Android Debug、JVM、Lint 和全量 Android TV Emulator 回归；此前版本 M4.43～M4.49 的焦点、72/92 键、密集 60 片库、播放解码及设置快速输入测试不得退化。
- 修改仅限**展示文字**，不更改请求协议、来源合法性校验、插件执行权限或媒体解析行为。
- 仍为独立 Draft PR，不合并 main/master；未使用 TCL 真机验证。版本 `0.4.50-alpha` / code 55。
