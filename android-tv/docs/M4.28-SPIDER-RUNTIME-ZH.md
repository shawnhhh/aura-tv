## 已实现

- 审核 FongMi/TV `fongmi` 分支 `JarLoader.java`、`BaseLoader.java`，保留 SDK 父加载器、可选 `Init.init(Context)`、`Spider.init(Context, ext)`、站点 `Net/Local` 注入与只读 DEX。接口对照独立实现；不增加受保护插件、外部 AAR 或第三方二进制。既有源码的 GPL-3.0 分发义务见 `CATVOD_GPL.md`。
- 站点身份改为 SHA-256，包括 JAR、站点 key、Spider 类名、ext 和请求头。修复同 key 更新配置或凭据仍复用旧 Spider/Cookie 的问题，也消除 JVM 字符串哈希碰撞导致复用的可能。
- 初始化失败会清理已创建的 Spider、Net、Dialog、JS 和临时 Cookie；单项销毁异常不阻断其他清理。
- JNI ABI 同时考虑设备支持列表和当前进程位数。保留旧 `assets/ftyguard_*`，增加标准 `lib/<abi>/lib*.so` 提取，限制文件数、单文件和总解压大小，校验缓存 SHA-256、只读化，拒绝路径穿越。不提前强制加载 JNI。
- IPC 串行化站点切换与播放请求；失效连接解绑，失败/超时 waiter 清理，限制请求及响应大小。绑定带独立代次，旧回调与旧 request ID 的回复不能影响新连接。
- 崩溃后下一次明确的详情/播放调用，最多先恢复一次最近成功的站点目录/运行时；不自动循环重试或重放先前的播放调用。失败站点切换不会恢复到之前的源。
- 服务启动时验证进程名必须是本应用的 `:spider`。每项操作的 32 秒独立看门狗终止自身进程，覆盖忽略线程中断的 JNI；主界面 IPC 有限超时并保留重连能力。第三方代码仍拥有应用 UID，这不是权限沙箱。
- 宿主日志不再输出插件 toast 文本或异常堆栈，只记录错误类型。传给 UI 的错误文本遮蔽 URL、Cookie、Authorization 和常见令牌字段。无法约束第三方插件自己写入系统日志，不能声称所有第三方日志已脱敏。
