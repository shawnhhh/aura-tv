# HERRIN M4.8 — 全屏直播、简洁设置与 TVBox 影视兼容性

## 用户实机反馈（2026-10-27）

- TCL T7L Ultra 直播已经导入 186 个频道，但停在巨大分组/频道按钮页面。
- `http://www.饭太硬.net/tv` 解析到 JPEG 内嵌 TVBox JSON（49 个点播站点、6 组直播），影视页面却为 0 部；设置显示 `InvocationTargetException`。
- 设置页导入明细占据过多空间，影视站点切换按钮远离直播导入按钮。

## 交互调整

1. 用户打开“直播”标签后，一旦频道列表完成读取，就进入首个（或本次会话选中的）频道的全屏播放。直播页面不展示分组按钮轨道。
2. 播放中按 **遥控器左键 / 确定键** 显示左侧抽屉：分组、频道、收藏筛选和频道查找。选择频道后继续全屏播放；返回先关闭抽屉，再返回首页。无频道时仍提供设置入口。
3. 默认设置页保留“影视源”和“直播源”两个输入框。“应用影视源”右侧只显示简短的 **读取中 / 成功 / 未获取到影片 / 导入失败**；“应用直播源”右侧同样仅显示 **读取中 / 成功 / 失败**。
4. “选择影视点”位于“应用直播源”旁边，支持手动在已解析的点播站点间切换；详细解析状态只出现在高级工具。
5. 为明确从 TVBox 导入的电影、Spider 目录放行 HTTP 海报，普通 HTTPS 授权目录的海报安全规则不变。

## 关于饭太硬站点加载失败的确切原因与改进

真实公开接口是合法 JPEG（后缀附有 Base64 JSON），并不直接包含影片目录。这份配置点播入口大多为加密的 `csp_*Guard` 类；没有一个简单可直接返回电影列表的标准 CMS API。旧版只尝试前三个站点，且反射层掩盖了内部错误。

本版：

- 对插件反射异常展开完整 `cause`，将内部实际故障显示到高级诊断并写到 `HerrinCatVod` 日志，便于用户截图和 `adb logcat` 定位。
- 仅对已明确应用、且已核对 MD5 的 Spider 文件尝试专有 `ftyguard_v7/v8.so` 运行库：按设备 CPU 架构安全读取已校验 ZIP 内的固定条目，限制大小、只读缓存，再尝试运行前初始化。
- 忽略优先级较低的云盘、片单、音乐、预告类，继续尝试更多的可浏览影片站点（上限 12），找到真实数据即停止。
- **只有真正获得至少一部影片，才显示“成功”**；配置元数据读取成功不会冒充影片已导入。

**验证边界：** 外部 `csp_*Guard` 的解密、JNI 及服务器兼容性高度依赖设备、ABI、插件内部行为。模拟器 CI 不执行不受控的公共插件，不能代替 TCL 实机验证。若改进后仍为“未获取到影片”，用户可进“高级工具与诊断”查看内部 `Spider ...` 异常，提交截图继续诊断；这不是已经实测解锁所有受保护影视站点的声明。网页 parse=1、网盘登录、完整 drpy2 运行时仍不在此轮范围。
