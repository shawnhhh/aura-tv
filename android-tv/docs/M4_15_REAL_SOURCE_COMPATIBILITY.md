# HERRIN M4.15 — CatVod 真实影视源结果兼容性

## 范围

针对用户从 TVBox 多仓导入的 Java `csp_*` Spider 站点。参考 [FongMi Spider 公开接口规范](https://fongmi.github.io/TV/spider/) 的目录、详情、选集、播放结果和字幕字段；不打包或运行第三方受保护 JAR 测试内容。

## 已实现

1. **详情补全封面**：首页列表若缺少 `vod_pic`，详情返回的合法 HTTP(S) 封面会补进原有影片模型；同时补全年份、角标、分类与简介。无效的 `javascript:`/`file:` 地址不能覆盖已验证封面。该补全沿用用户已应用的来源授权。
2. **保留真实选集名称**：解析 `vod_play_from` 和 `vod_play_url` 多线路时保留「第一集／正片」等显示名称，不再全部硬改成「第 N 集」；播放 ID 仍是 Spider 原样返回的 opaque ID，不猜测 URL，不修改请求令牌。
3. **多画质结果**：在 `playerContent` 的单一 URL 之外支持标准交替标签/URL 数组，以及 `Url.values` + `position` 对象。优先选用户配置推荐的画质；若首项非法或不符合本次 HTTP 许可，则回退第一个合法直链。没有实现画质菜单，不随意启动网页播放。
4. **WebVTT 外挂字幕**：解析标准 `subs` 数组（URL、名称、语言、格式），最多 6 条；仅接受用户本次许可的 HTTP(S) WebVTT，SRT/ASS 不会被错误交给 Media3 的 WebVTT 解码器。字幕通过 Spider IPC 回传主播放器，并在主进程重新校验地址/语言/HTTP 许可。
5. **安全边界**：`parse≠0` 或 `jx≠0` 的网页解析请求仍返回明确“不支持直接播放”，不做网页嗅探、DRM 绕过或执行不明脚本。第三方 DEX/JNI 仍只在显式授权或已有精确 JAR 校验绑定时执行。

## 测试与剩余风险

- 增加纯 JVM 测试：真实选集名称、详情缺图补全、无效封面回退、CatVod 多画质数组/对象、HTTP 许可、WebVTT/SRT 过滤、IPC 字幕信息往返及网页解析标志。
- CI 编译/单测/Lint 与 Android TV API 30 模拟器回归结果以最新提交检查为准。
- **不等于真实饭太硬 Spider 已出画面**：它包含受保护的 ARM JNI，部分插件还要求 Activity、代理端点、私有运行时或网盘登录。x86 模拟器不执行该第三方代码；是否能在 TCL T7L Ultra 成功获取电影列表/封面及播放，需要用户授权设备上的实测日志。
- 继续保留 Draft PR，不合并，不导入未经许可的影片资源或影视源二进制。
