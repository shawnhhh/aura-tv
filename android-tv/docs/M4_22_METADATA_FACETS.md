# HERRIN M4.22 — TMDB 主创、地区与年份组合筛选

## 本阶段行为

- 与 M4.21 一样，影视源单独提供稳定影片 ID、选集、播放线路和地址；官方 TMDB 仅提供展示字段。
- 精确标题及首映年份匹配后的 TMDB 官方 detail 请求通过 `append_to_response=credits` 同时取影片的演员、导演、主创、国家地区。电影使用 `production_countries`；电视剧使用 `origin_country` 和 `created_by`。**不**以影片语言、域名猜测国家。
- 首页和搜索页右上角「筛选」打开 TV 原生 D-pad 页面；分类、年份、演员、导演/主创、国家/地区各自可选择一个选项，跨维度为 **AND**；每行「全部」撤销该维度，顶部「重置所有条件」清空全部。结果直接进入原有选集与播放链。
- 正在刮削、未配置 Token、匹配失败、当前目录超出首批 80 部限制，均在筛选页显式告知，避免将已扫描子集称作全库；演员、导演、地区没有实际元数据时不会虚构字段。
- 官方资料与影视源身份完全隔离；关闭 TMDB 会恢复原始简介/海报/分类/人员/地区展示字段。

## 已知限制

- 无 TMDB Token 时只能用源内年份和原分类，主创、地区缺失时为空；匹配失败不会凭猜测补充。
- 当前片库每轮最多刮削前 80 部，先显示目录，后台限并发 3 个请求；每部匹配成功后另外请求一次 TMDB detail，搜索/详情失败互不阻塞。
- TMDB 提供的导演、主创、地区可能本身不全，属于第三方开放数据库质量局限；不等于网易爆米花私有刮削引擎。
- 豆瓣官方评分没有取得授权，仍不接入。
- 本地环境没有 Android SDK，须以 GitHub Actions JVM/Android TV 模拟器 CI 与用户 TCL 实机作为最终验收，Draft PR 继续保持未合并。

## 验证项目

1. 演员与年份 AND、逐项清除及全部恢复。
2. 同名不同年份映射到对应 TMDB ID/detail，播放 URL/影视源 ID/选集不变。
3. 影片语言不用于推测地区；资料缺失不进入已选的导演/地区结果。
4. D-pad 从筛选页最后一行按下聚焦结果首张海报并滚入视野，确定进入详情，返回筛选页。
5. 修复旧版 3 个 CI 问题：TMDB 非法双斜杠路径、TVBox VIP flags 去重后的 32 项上限、模拟器惰性列表内状态文本滚动后断言。
