# M4.28 播放请求诊断与有界恢复验收报告

基线：`e1e8d6f44586cc2d8a7af5f1fc1b9777f0eaa0a2`。分支：`feat/herrin-m4-28-playback-diagnostics-20261029`。实现提交：`52e975e03da8e1d5f505d96f2fb33e1746039460`。独立 Draft PR：[ #34 ](https://github.com/shawnhhh/aura-tv/pull/34)。

## 已实现

- `PlaybackFailureHints` 将 HTTP 401 身份验证、403 权限拒绝、404/410 地址失效、429 限流、5xx 服务异常分别分类；网络、Android 网络策略、HLS/DASH 清单、媒体容器、解码器、音频输出和直播窗口也分别分类。错误提示不再拼接与实际根因不符的通用文案。
- 异常链扫描使用对象身份去重，最多 16 层；仅提取 100–599 的 HTTP 状态及正则允许的 Media3 错误代码，不显示或记录 URL、签名参数、Cookie、Token、响应正文或异常消息。
- `PlaybackFormatRetry.Session` 为每次明确播放选择提供单向、有限恢复状态。仅使用来源已给出的最多 8 个去重地址；每个无扩展名地址最多依次尝试默认嗅探、HLS、DASH。自动恢复耗尽后不重新循环。用户明确按「重试」才重置预算并从首地址重新开始。
- HTTP 错误不会触发同地址的 MIME 猜测。429 停止自动切换，避免向备用来源继续发送自动请求；Android 权限和明文策略错误也不自动切换。
- 每个备用地址重新推断格式，不继承前一个地址的 HLS/DASH MIME。合法 MP4 声明得到规范化；未声明 MP4 保留 Media3 progressive 嗅探。URL 查询参数和片段中的 `.m3u8` / `.mpd` 不再被当成格式依据，避免签名或无关参数锁定错误解析器；无扩展名 HLS/DASH 仍可有界重试识别。
- 自动切换与用户重试保留当前点播位置，直播切换不沿用点播 seek。UI、焦点、返回、剧集/线路选择、字幕、Cookie 会话隔离、硬件解码配置和画质音效识别接口保持现有设计。

## 自动回归

JVM 测试覆盖 HTTP/媒体分类、隐私允许列表、循环异常链、8×3 上限、耗尽后反复错误、重复地址、每地址 MIME 隔离、429、策略错误、误导查询参数及手动重试预算重置。

新增 `PlaybackDiagnosticsIntegrationTest` 使用本机 TLS MockWebServer 和已有原创视频，覆盖：无扩展名 MP4、HLS、DASH 实际解码出帧；403 HLS 主地址切换到无扩展名 MP4；401/403/404/429/503 提示与 URL 参数脱敏；429 不请求备用地址。DASH 的 MPD、init 和 media 分段由仓库已有 `synthetic.mp4` 无损 remux 得到，不含第三方媒体或受保护二进制。生成命令：

```sh
ffmpeg -i synthetic.mp4 -map 0:v:0 -c copy -f dash -seg_duration 2 manifest.mpd
```

## 尚未实现及实机验收

- 本模块不接入本地代理，不改变 DRM、来源权限或跨域访问授权，不进行网页解析或地址发现。
- 自动恢复上限约束的是应用层地址与 MIME 尝试；Media3 自身每次加载的有限重试仍按默认策略执行。
- 不把模拟器出帧当作 TCL T7L Ultra 真机验收。真机后续需验证：遥控器焦点/返回；首地址和备用地址起播；进度保留；直播切换；合法 HLS/DASH/MP4、4K 与硬件解码；电视自带扬声器的 Dolby/HDR 状态。当前无需用户手动测试。
