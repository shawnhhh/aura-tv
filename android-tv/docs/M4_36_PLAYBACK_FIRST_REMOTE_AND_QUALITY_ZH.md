# HERRIN M4.36 — 普通用户全屏播放与电视遥控器

## 来自 TCL T7L Ultra 的真机反馈

- 选择影片或集数后，先出现大幅影片详情及“Spider 解析中”技术页，不是直接进入视频。
- 影片已能产生真实画面，但播放器里的左右键无法快进/后退，下键不能移动到控制栏。
- 播放中无法直观看到实际清晰度。
- 用户明确要求内部 Spider/CatVod/插件日志不要显示在普通用户的播放页面。

## 本次实际实现

1. **影片点开直达视频**：当前影视仓已加载的、可确定首条选集/线路的影片海报默认进入 `screen=player`；Spider 影片缺少选集时，进入全屏普通加载界面，在后台取 `details` 并选取第一条真实选集/线路后解析，无技术页、不猜 URL。多季整合作品仍可先看详情选择季；首页保留独立“详情”操作。
2. **真全屏加载**：若视频媒体地址尚未获取，进入黑色全屏加载层，用户只看到“正在打开影片…”与“返回选集”；成功后不需要额外点击直接切换 Media3 视频。如果失败，仅展示“暂时无法播放”以及“重新播放”“返回选集”；内部 Spider 崩溃、代理状态和原始错误字符串不会出现在普通播放页面。
3. **电视遥控器重映射**：播放器根 Compose 节点可获得焦点；左/右键直接 seek -10/+10 秒；确定/下键显示控制栏并将焦点移至播放/暂停；控制栏内左右导航各项按钮，上键返回沉浸播放画面；物理播放/暂停、快进/快退媒体键仍有效。
4. **沉浸式控制栏**：播放器 READY 后，控制栏在无焦点操作时约 8 秒自动隐藏；焦点在控制栏时保持可操作。不再始终把控制栏、返回及说明文字压在视频画面上。原播放器原生 PlayerView 只负责视频输出，保留 Compose 控制区。
5. **清晰度**：控制栏显示 Media3 实际得到的视频尺寸对应的 720p/1080p/1440p/4K 等；未选择视频轨/尚无视频尺寸时展示“清晰度识别中”，不从来源文件名或影视源宣传中断言 4K 或 Dolby Vision。
6. **旧回归同步**：M4.35 改为按需选择影视点后，原始两项电视模拟器测试仍等待“导入立即加载电影”，造成 2/89 失败；本次更新为验证导入配置成功后**先选择影视点再浏览**，不回滚用户明确要求的快速导入设计。

## 自动验收

- Android Debug：静态检查、JVM、Lint、assemble APK；
- Android TV API 30：完整现有测试，保持 Spider 合法 MP4/HLS 出帧、屏幕有画面、遥控器焦点回归；
- 新增 `PlayerQualityLabelTest`：验证 720p/1080p/1440p/4K、未知清晰度不能冒称 4K；
- 新增模拟器遥控器实际键盘注入测试：DOWN 焦点到播放/暂停、UP 回画面、RIGHT/LEFT 真实进度跳转、CENTER 重新聚焦、Media3 视频规格有显示；
- TCL 真机仍要确认：播放时左右寻址、下键/确定焦点、分辨率标签、声音与 HLS/4K 等真实流播放。模拟器不证明厂商 Dolby/HDR 最终输出。
